# BetSim

竞彩足球「胜平负」模拟投注器：**随机生成 21 场虚构对阵 → 从 8907 组真实 B365 赔率池取盘 → 虚拟余额下注 → 按赔率倒数加权开奖 → 逐场结算与盈亏反馈**。

纯前端单文件 HTML，无后端、无账户、无真实货币，刷新即重置。

[在线试玩](https://ab123666.github.io/BetSim/)

## 特性

- **赛事生成**：`TEAM_CITY`（100 个地名）× `TEAM_NAME`（100 个队名）≈ 1 万种组合，35% 概率只用队名、其余拼成「地名 + 队名」；同一批内队名去重（单次最多重试 100 次）。
- **赔率来源**：`REAL_ODDS` 内嵌 8907 组 B365 胜平负赔率（约 124 KB，占文件三分之二），全程零网络请求。
- **隐含概率**：`p_i = (1/o_i) / Σ(1/o_j)`，把赔率倒数归一化，得到去水后的三项概率（`calculateProbabilities`）。
- **开奖逻辑**：`settleMatch` 按 `1/odds` 加权抽样，等价于以隐含概率掷一次骰子；开奖后该场锁盘，不可再投。
- **投注**：金额合法性 + 余额校验；同一场同一选项的多笔下注会合并统计总额 / 潜在返还 / 笔数（`getMergedBets`）。
- **一键开奖**：按投注队列逐场结算，卡片脉冲约 500 ms 后翻出结果，胜 / 负各一套 Web Audio 合成音效。
- **自动补场**：每开完一场立刻补一场新比赛，列表始终维持 21 场（`CONFIG.MATCH_COUNT`）。
- **视觉反馈**：HTML 元素粒子爆炸（桌面 20 颗 / 移动端 12 颗）、余额逐位滚动、Toast 提示、开奖中呼吸动画。
- **余额**：初始 `10000.00`，可手动覆盖修改；只存内存，刷新回到初始值。
- **移动端**：`viewport-fit=cover`、头部高度按安全区动态计算、网格列数与粒子数随宽度收敛。

## 快速开始

```bash
git clone https://github.com/ab123666/BetSim.git
cd BetSim
python -m http.server 8000
```

打开 <http://localhost:8000>。也可以直接双击 `index.html` —— 没有跨域资源，`file://` 同样能跑。

## 使用

1. 点某场比赛的主胜 / 平局 / 客胜赔率，弹窗输入金额后确认，余额立即扣减。
2. 右上「修改」可直接改写余额（覆盖式，不做增减）。
3. 「一键开奖」按投注顺序逐场结算：赢则返还本金 × 赔率，输则本金不退。
4. 「刷新」丢弃当前 21 场并重新生成，未结算的注单一并清空。

## 计算说明

设某场三项赔率为 `o_h / o_d / o_a`：

- 隐含概率：`p_i = (1/o_i) / Σ(1/o)`
- 返还率（综合赔率）：`R = 1 / Σ(1/o)`。本仓库赔率池实测 `R` 中位数 `0.9487`、均值 `0.9482`、区间 `0.8571 ~ 0.9731`
- 开奖抽样：`r = random() × Σ(1/o)`，落在 `[0, 1/o_h)` 为胜、`[1/o_h, 1/o_h + 1/o_d)` 为平、其余为负 —— 与 `p_i` 同分布
- 单注期望：`E = p_i × o_i − 1 = R − 1 < 0`，长期必亏，和真实的竞彩盘口一致

`CONFIG` 里的 `MARGIN = 0.08` 与 `MIN_BET = 1` 目前是预留常量，未参与计算与校验。

## 已知限制

- 只有「胜平负」单一玩法，没有让球、比分、总进球、半全场、串关。
- 状态不落盘（无 localStorage），刷新即回到 10000 元、21 场全新对阵。
- 赔率池是静态快照，不随比赛进程变化，也没有走水 / 封盘 / 退款。
- 音效需要一次用户交互才能启动（浏览器自动播放策略），已用增益 `1e-5` 的静音振荡器给标签页保活。
